# SCAU Link · 桌面界面设计 02

本版以托盘 Mini 为默认入口，采用渐进展开。沿用松绿、浅灰、纸白和 Windows 系统字体，保留完整管理窗口作为次级入口。

这是独立的 HTML 交互设计稿，尚未接入认证核心。所有账号、时长、网卡地址、连接检查和恢复事件均为演示数据；连接、断开和设置仅改变浏览器内的演示状态，不会运行客户端、修改网络或 Windows 设置。

## 从 Mini 开始

- [mini.html](mini.html) / [index.html](index.html)：默认打开托盘小窗。
- [overview.html](overview.html)：设计评审总览，默认只展示三张渐进展开示意，其余状态和完整页面折叠。
- [previews/concept-02/](previews/concept-02/)：本版全部页面的实际浏览器截图。

所有资源均已包含，不依赖 CDN。可以在本目录启动仅本机访问的预览：

```powershell
python -m http.server 53180 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:53180/mini.html`。预览服务不提供认证接口。

## 信息如何展开

| 层次 | 用户看到的内容 | 进入方式 |
|---|---|---|
| 默认 Mini | 当前状态、简短说明、在线时长、一个主要操作 | 左键托盘；在线时约 360 × 330 px |
| 连接详情 | 网线、校园网认证、互联网检查、脱敏账号、当前网卡 | 主动点“连接详情”；展开后约 360 × 559 px |
| 聚焦面板 | 账号、偏好、当前网卡或最近记录，每次只处理一件事 | “更多”菜单或详情内入口；均带返回 |
| 完整窗口 | 网卡管理、完整记录和其他管理页面 | “更多 → 打开完整窗口”；1060 × 730 px |

在线时不展示账号密码输入框、检查卡片、恢复过程或日志列表。未连接时，先点“连接校园网”才进入账号面板。认证拒绝时只提示检查账号；自动恢复时先显示简短原因和“停止重连”，详细过程需再展开。登录选项、网络地址、启动与窗口设置也分别折叠。

## 可以体验的交互

- 左键托盘打开或收起小窗；右键打开短菜单。
- 点击桌面空白、收起按钮或 Esc 可隐藏小窗。Esc 先关闭更多菜单、返回上一层或折叠详情，再收起。
- 隐藏小窗和关闭完整窗口均保留当前会话；重新打开从紧凑状态开始。退出应用另有确认。
- Mini 和完整窗口在同一个页面内切换，共享当前演示连接与偏好。没有另开一个独立会话。
- 登录表单支持空值校验、密码显示切换和 Enter 提交。仅使用任意演示内容，不需要真实密码。
- “体验连接流程”模拟约两秒的认证过程；收起后仍会完成，但不会自动弹出小窗。
- 手动断开、取消认证或停止恢复会清除待执行的连接动画，保持离线。
- 顶部演示状态选择器属于设计预览工具。自动恢复是固定状态示意，不代表已运行长期稳定性测试。
- 最近记录可以导出脱敏演示 JSON；完整记录保留搜索与异常筛选。

原型不使用 localStorage、IndexedDB 或 Cookie 保存凭据。交互页使用 `connect-src 'none'` 禁止网络 API；密码不进入日志或诊断导出。刷新页面重置演示状态。

## 原生落地约定

1. 托盘图标单击打开 Mini，右键打开短菜单；浮窗根据图标所在显示器的工作区和 DPI 定位，避免遮住任务栏或超出屏幕。
2. Mini、完整窗口和认证核心共享一个会话控制器。显示、隐藏、切换页面不得启动第二份认证或发送下线请求。
3. 点击外部、Esc、关闭完整窗口默认只隐藏视图。明确的“断开连接”与“退出并断开”才停止认证；退出不与普通关闭混用。
4. 连接状态、校园网认证和互联网可达性分别取自真实事件。不可仅凭认证成功就把互联网检查标为通过。
5. 恢复过程只在需要处理时提示，不自动展开日志；明确拒绝、用户停止和服务端下线优先于恢复策略。
6. 账号修改用于下一次主动连接。密码不写入配置或普通日志；启动、通知和外观等仍需后续原生实现。
7. 展开控件保留键盘焦点，收起后焦点回到托盘入口；状态同时用文字和图标表达，低动态效果偏好下关闭动画。
