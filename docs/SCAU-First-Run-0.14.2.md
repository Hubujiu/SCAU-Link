# SCAU Link 0.14.2 预览版

本版修复摘要缺少显示字段时提前放弃详情查询的问题，补充套餐返回内容的脱敏诊断，并在“记录”页显示套餐查询结果。下载安装包见 [GitHub Release](https://github.com/Hubujiu/SCAU-Link/releases/tag/v0.14.2-preview)。

安装后输入校园网账号密码，选择有线 802.1X、SCAUNET Web 或 SCAUNET_1x。套餐查询使用保存的凭据独立访问学校自助服务；认证联网成功不等于自助服务登录成功。

普通窗口的已连接主页或账号列表可见时检查套餐。正常数据五分钟刷新；隐藏、最小化、小窗和其他页面不主动轮询。余额未知时展开主页详情查看提示，也可进入“记录”搜索“套餐”。

故障复测请确认实际运行 0.14.2，在连接主页等待约两分钟，然后发送 `%LOCALAPPDATA%\ScauLink\logs\desktop.jsonl`，附出错时间、连接方式和版本。无需发送整个数据目录、密码、Cookie、抓包或学校原始页面。

本版可区分 HTTP 响应不完整、字符编码错误、网页返回、JSON 格式不兼容、空信息列表及未识别字段。具体含义见 [套餐查询说明](Package-Query-0.14.2.md)。报告故障的测试电脑仍需复测，不将离线回归当成跨机器实测。
