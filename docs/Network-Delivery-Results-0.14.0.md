# 0.14.0 更新验证

认证源代码未修改，本版启用确定性编译/链接，核心二进制摘要与 0.12.0/0.13.0 不同，因此从旧版升级保守采用完整安装流程。本轮没有交接真实校园网连接，也不把历史无线认证记录当成本轮重测。此后同一工具链下没有改变的核心可生成稳定摘要，支持识别仅桌面文件变化的更新。

新增隔离进程验证：正在运行的桌面文件被替换后，原桌面与独立模拟核心均保持原进程运行；核心文件摘要和修改时间不变，未执行安装器。故意锁定中间目标文件后回滚已替换的文件；签名有效但含异常路径的包也被拒绝。清理旧副本不会停止仍映射文件的进程，进程退出后可完成清理。

规则检查覆盖在线/离线、认证繁忙、交互繁忙、空闲和两类更新的组合；核心或运行库摘要变化时不允许按不断网方式安装。兼容说明篡改、绑定到其他完整安装包的兼容说明被拒绝。发布后的真实签名包下载与磁盘替换另附 Release 验证文件。

最终 Release CTest 35/35 通过，更新模块 267 项检查；[GitHub Windows 独立构建](https://github.com/Hubujiu/SCAU-Link/actions/runs/43668273796) 同样通过。完整重新构建核心及依赖后，摘要保持 `4716aca37993cc6275da43df9d8a1feaf02b23a315c96a3caf53e3430d2eca13`，见 [重建记录](network-delivery-0.14.0/core-reproducibility.json)。

普通用户的本地缓存和公共 GitHub 下载两条路径均已使用真实发布签名包验证。公开下载共 60,795,978 字节，SHA-256 为 `7caed585592711c75dd1440c857f81b2f3f36208c4ba406be36c8b7426b5b0d9`。原生测试进程作为桌面进程替身，在自身文件被替换后继续运行；真实认证程序以明确挂起方式保持映射，没有执行认证代码。测试核对原进程及核心映射存活、五个受保护文件未变、三个目标程序摘要与发布文件一致。当前校园网进程、程序、账号目录和设置未变，绑定以太网的上网检查通过。见 [发布后验证记录](network-delivery-0.14.0/live-update-verification.json)；该记录也作为独立 Release 资产提供，已发布安装包没有重写。

新增状态提示和确认框没有以实际点击记录作为通过证据；先前前台输入因锁屏不可用，本轮不依赖窗口切换开展核心测试。其他电脑、Windows 实际重启及长时在线仍未新增验证，继续预览分发。
