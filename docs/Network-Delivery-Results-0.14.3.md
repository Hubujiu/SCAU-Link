# 0.14.3 自助查询拒绝识别验证

2026-11-15，0.14.3 预览版。发布时间以 [GitHub Release](https://github.com/Hubujiu/SCAU-Link/releases/tag/v0.14.3-preview) 为准。

## 本轮实际验证

- 完整 Release 构建、CTest 36/36 通过，包含两个原生合成主页场景。
- 新增回归覆盖 54 字节短回复、有效拒绝码 0/1/2 及有界未知码、代码零的存在性、UI 状态文本，以及重复、冲突、前导零、负数、嵌入片段和越界数字的拒绝。收到拒绝不再发起详情请求。
- 原生 OpenSSL 探针使用空账号、空密码的合法编码查询，不读取凭据仓库；学校返回完整 HTTP 200、54 字节、拒绝码 0，生产解析器正确分类为 AuthError（6）、摘要 LegacyRejected（15）。只发布数字与布尔证据 `network-delivery-0.14.3/public-rejection.json`。
- 使用本机保存的自有账号进行独立只读查询，取得摘要、余额、账期及周期费用；没有启动或停止校园网认证。脱敏证据为 `network-delivery-0.14.3/own-package.json`。
- 认证核心及四个应用本地 VC++ 运行库与 0.14.2 摘要相同；本版使用现有签名发布身份及固定更新校验规则。

## 未验证与限制

报告电脑的旧日志只证明完整 54 字节正文无法解析成预期 JSON。其具体拒绝码尚未知，不能用本机空查询的代码 0 替代该电脑的实际结果。本版修复错误响应处理，不宣称已经恢复其余额查询。

未获取测试人员密码或学校原始响应；没有根据未知的密码字符类型更改编码，没有尝试猜测密码、去掉账号后缀或自动换接口登录。真实认证进程保持运行，未安装覆盖当前客户端或切换网络。没有在本轮验证新无线认证、实际重启、漫游、长时在线或完整视觉检查。
