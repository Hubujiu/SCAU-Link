# 0.13.0 更新功能验证

本轮只新增 GitHub 分发和更新功能，没有交接当前校园网连接。认证核心 SHA-256 与 0.12.0 相同：`615df8d16fb23c4815846fa13312694e59043fb966bf19b81693bc9d5f769245`。此前真实无线认证、上网与恢复证据保留在 [0.12.0 报告](Network-Delivery-Results-0.12.0.md)，不标为本轮重测。

最终 Release CTest 35/35 通过。新增更新测试覆盖签名篡改、错误来源和通道、降级、下载损坏、缓存复核、空闲/联网/交互门槛，以及真正的跨进程安装交接。隔离父进程、独立助手和无网络的安装夹具验证：父进程存活时不得运行安装；安装前持有文件防写锁；包含中文和空格的目录正确传递；成功与失败退出码均记录，并启动原路径程序。

真实安装包使用不同安装标识的 QA 变体，在普通用户下安装到含中文和空格的隔离目录。安装退出码为 0，三个程序摘要均与最终构建一致，静默重启未产生第二条认证，卸载退出码为 0。原有线客户端和核心进程保持不变，账号目录和设置摘要不变，绑定以太网的互联网检查通过。结果见 [安装交接记录](network-delivery-0.13.0/installer-qa.json)。

GitHub 公共 API 与 Release 安装包下载测试已在发布后通过。普通用户进程无 Token 检查当前版本，并模拟 0.12.0 完整下载 58,275,942 字节的 0.13.0 安装包；原生模块验证签名，完整文件摘要为 `f899d8ad1a90522bda950d31cfcb1047a21b7fe371c8d0389fee0b0ffd371085`。测试没有执行正式安装或校园网登录；原进程、账号目录、设置与程序文件不变，绑定以太网上网检查通过。见 [发布后记录](network-delivery-0.13.0/live-update-verification.json)，Release 也附有同一记录。发布包冻结在测试之前，其验证说明指向此独立资产，没有重写已发布安装包。

[GitHub Windows 2022 独立构建](https://github.com/Hubujiu/SCAU-Link/actions/runs/43617638109) 已通过 35/35 CTest，源代码对应发布标签 `v0.13.0-preview`，提交 `cebcf1d4bad91728b05fa08301b462e16619247f`。本机和发布包的源码检查均未发现发布私钥、私人配置或抓包。

Windows 实际重启、其他电脑、长时在线、漫游、休眠、热插拔，真实改密及校园网暂停/恢复没有在本轮新增实测。依然以预览版分发。
