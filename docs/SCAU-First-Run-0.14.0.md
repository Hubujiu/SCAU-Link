# SCAU Link 0.14.0

校园网连接和保存账号沿用 [0.12.0 说明](SCAU-First-Run-0.12.0.md)。本版修改更新流程：设置页显示“无需断网”或“更新时可能断网”。

“无需断网”的更新可在线安装，认证进程持续运行，完成后显示“下次启动生效”。若提示可能断网，手动安装需再次确认，自动安装等待连接断开。无需开启额外设置，小窗设置保持简洁。

0.13.0 及更早版本首次升级仍需按旧流程退出并安装本版。之后使用 [新的更新规则](Updates-0.14.0.md)。本轮验证与限制见 [验证报告](Network-Delivery-Results-0.14.0.md)。
