# SCAU Link 0.14.1 预览版

本包修复套餐查询目标丢失、TLS 冷却不结束和无线查询接口选择，加入余额与费用的“预计到期”。安装包和签名更新信息通过 [GitHub Release](https://github.com/Hubujiu/SCAU-Link/releases/tag/v0.14.1-preview) 发布。

运行安装包选择安装目录，启动后输入校园网账号密码，选择 Web 或 SCAUNET_1x。套餐查询使用保存的凭据独立访问学校自助服务；主页普通窗口可见时会查询。

若显示“账号未确认 · 套餐账号 …”，只表示当前在线身份未核实，展示的余额来自标明的保存账号。若没有余额，主页会显示套餐查询状态，可在展开详情中查看完整提示。

正常数据每五分钟刷新；界面每 15 秒检查是否到刷新时间，隐藏、最小化和小窗不主动查询。失败有独立重试，见 [查询说明](Package-Query-0.14.1.md)。

复测仍失败时，记录版本、查询提示和 `%LOCALAPPDATA%\ScauLink\logs\desktop.jsonl` 中 `package_query_` 开头的日志；不要提供账号密码、会话 Cookie、抓包或原始服务器响应。

本机只读实网查询与合成 UI 场景已验证。其他电脑、真实无线新登录后的本版查询、长时在线和重启仍需复测。
