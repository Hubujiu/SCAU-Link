# SCAU Link 0.12.0 使用与实现说明

安装后在账号页保存校园网账号和密码，在连接页选择有线 802.1X、无线 Web 或无线 802.1X。三种模式共用账号列表，按从上到下的顺序尝试；明确的账号拒绝重试一次后换下一行。环境错误、未知认证结果及手动断开不会盲目换号。

开启“开机自启”后，启动默认复用上次手动选择的连接方式。“开机连接”也可以指定第一种方式，再逐步添加备用方式；自动连接首个方式长时间未完成时按顺序继续，成功后停止。自动尝试备用方式不会覆盖上次手动选择。静默启动不显示窗口或失败通知，托盘仍可打开。

## 无线和凭据

- 无线 Web 自动连接 `SCAUNET`，发现并使用本机实测的学校 Portal，不需要导入认证配置或手动填写请求地址。支持现网 `InterFace.do` 表单及旧 authAPI 元数据格式；实际认证、保活和退出采用发现并验证的同源接口。
- 无线 802.1X 使用固定配置名 `SCAUNET_1x`，Windows WLAN/EAP 直接使用已保存凭据。网络配置在所有用户存储中，EAP 凭据只写给当前调用者，不使用 Windows 登录凭据，不生成随机可见网络名。诊断探针可以使用随机配置名，产品默认不使用。
- 密码保存在当前用户的 Windows 凭据管理器，不写入日志、命令行或安装包。首次使用自动选择物理网卡，本机协议配置按需生成。
- 无线模式不需要 Npcap；有线模式需要已有 Npcap/WinPcap。操作系统需具备有效 IP/DNS 配置。本机原 WLAN 的 DHCP 被关闭且无有效静态地址，实验临时启用 DHCP 后精确还原；产品不会自动改写用户 IP 设置。
- 认证核心意外退出后自动恢复。无线配置保持稳定 MAC 设置，避免恢复时因随机 MAC 变化产生新的身份和地址等待。

现网 Web 可能按设备保留上网状态。如果无需提交新凭据就能通过该无线接口访问外网，显示“账号未确认”，不会把保存账号误标为“活跃中”，也不会注销不属于本次登录的会话。

## 套餐

查询使用当前物理接口的 IP、MAC、DNS，避免被虚拟网卡和代理 DNS 影响。新安装没有有线配置也能查询。重连后旧请求不能覆盖新连接数据，短暂失败会退避重试；可见主页和账号页定时刷新，隐藏、小窗和静默状态不主动查询。

主页显示当前认证账号、余额和已有期限；账号横条显示余额、周期费用、下次扣费。实际扣费日期和可支持的“预计下次扣费”明确区分；未知字段仍显示未知，不通过余额推算账号失效日。

## 界面与安装

设置只保留小窗模式、开机自启、静默启动和渐进展开的开机连接方式。自动恢复、通知、关闭到托盘固定开启。小窗居中，设置只保留退出小窗模式。原生菜单、选择框采用统一圆角和弹簧过渡。

安装向导支持自定义盘符和目录。应用本地携带签名验证过的 Microsoft VC++ 运行库；安装不启动认证、不安装网卡驱动、不结束正在联网的客户端。源码和脱敏验证记录随包提供。

本机真机测试、失败对照和未验证范围见 [0.12.0 实验报告](Network-Delivery-Results-0.12.0.md)。本版仍标为预览版；其他电脑、Windows 实际重启和长时在线没有据此获得验证。
