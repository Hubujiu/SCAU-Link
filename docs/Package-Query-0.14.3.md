# 旧自助接口拒绝响应的识别

0.14.3，2026-11-15。发布状态以 [GitHub Release](https://github.com/Hubujiu/SCAU-Link/releases/tag/v0.14.3-preview) 为准。

## 反馈日志与定位边界

0.14.2 的复测日志中，三次新诊断均为完整 HTTP 200、传输完成、网络/TLS 错误码 0，响应体固定 54 字节，摘要结果 4（无法解析 JSON），没有详情入口或财务字段。这次确认了失败发生在已收到完整摘要响应之后，而非未升级、未触发查询或 TLS/响应收取失败。

使用不含真实账号密码的空查询，已在相同固定学校端点复现 54 字节的旧协议拒绝标记 `&errorMsg=0&`。0.14.2 会将它误报为 JSON 格式无法解析。本机有效账号则正常取得摘要、余额与周期费用。

报告电脑的日志没有保存响应原文，因此同样的字节数还不能唯一确认其具体拒绝码。不能直接判定对方密码错误，也不能声称 0.14.2 的详情入口修复已经解决该电脑的实际问题。本轮没有该电脑的凭据或远程访问，密码字符类型暂不清楚，未修改请求编码、账号或密码。

## 本次修复

- 在 JSON 解析前识别完整的旧协议拒绝标记，允许外围空白/BOM，数字有界；拒绝重复、冲突、负数、前导零和嵌入 HTML/JSON 的相似片段。
- 真实拒绝归为 `PackageState::AuthError`（6），而非 `Unsupported`（7）；不会继续猜测详情入口或把缺失余额显示为零。
- 主页展开详情显示具体拒绝码。“记录”页显示“套餐查询：登录未通过”。日志新增 `package_query_legacy_error`，只记录数字；`package_query_summary=15` 表示已识别旧协议拒绝。
- 错误码 0 按旧接口语义显示“自助服务账号或密码未通过”；代码 2 显示“自助接口拒绝访问”；其他拒绝码显示学校拒绝查询，不套用修改密码权限的解释。

认证联网和自助账务查询是两条独立链路。校园网已经放行，不代表保存凭据通过了自助查询接口。正常套餐五分钟刷新；识别到查询登录拒绝后按现有认证错误规则，完成后至少 60 秒再允许查询，而非此前未知响应的 15 秒重试。

## 复测与发布边界

确认实际运行 0.14.3，在普通窗口的连接主页展开详情，等待一次查询即可。请提供提示中的拒绝码，或 `%LOCALAPPDATA%\ScauLink\logs\desktop.jsonl`；不需要密码、账号文件、抓包或学校原始响应。若仍是未知格式而没有拒绝码，继续保留未知，不能按长度猜一个错误码。

本版认证核心和四个运行库的摘要与 0.14.2 相同，签名兼容说明匹配时可使用无需断网更新；运行中的界面仍在下次启动时加载新代码。发布过程不覆盖当前运行客户端、不结束认证或切换网络。

已验证的本机正反例与离线回归见 [验证报告](Network-Delivery-Results-0.14.3.md)。报告电脑仍需确认其实际拒绝码。
