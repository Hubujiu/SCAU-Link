SCAU Link · Windows 原生安装版

安装向导可输入路径或浏览选择目录，支持中文、空格和其他盘符。
默认安装到当前用户的 LocalAppData\Programs\SCAU Link，不要求管理员权限。
开始菜单快捷方式默认勾选，桌面快捷方式可选。
完成页“启动 SCAU Link”默认不勾选；安装过程不启动认证、不安装网络驱动、不结束现有客户端。
程序启动后仍按已有规则自动读取保存的凭据并登录。

保持 SCAU-Link.exe、scau-auth.exe、scau-update.exe 与运行库在同一目录。
0.13.0 起支持设置页手动更新，以及空闲时自动检查、下载；断开连接后才可安装。
更新核对签名和摘要，等待应用正常退出后安装到原路径，不主动断开校园网。
更早版本需手动安装本版一次。

已包含应用本地的 Microsoft Visual C++ x64 运行库，不改动系统运行库。
有线认证需要现有 WinPcap/Npcap。未检测到时，完成页提供 Npcap 官网下载入口，由用户自行安装。
首次使用只需填写账号和密码；网卡及学校认证参数自动在使用者的电脑生成，不需要认证配置导入。安装包不包含私人配置或抓包。

在 Windows“已安装的应用”中卸载，或运行安装目录下 uninstall 目录中的卸载程序。
卸载仅移除本安装包的文件和快捷方式，保留用户账号、密码、设置和认证配置。
更改安装路径时，仅迁移本客户端原已启用的开机启动路径，不主动开启开机自启。

许可证、依赖说明和完整对应源码在 docs 目录，source.zip 包含应用及安装向导构建代码。
本安装程序使用 Inno Setup 7.1.1，https://jrsoftware.org/；许可证见 Inno-Setup-LICENSE.txt。
