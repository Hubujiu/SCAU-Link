# SCAU Link 0.14.3 预览版

本版修复旧自助接口拒绝响应被误报为“数据不可用/格式无法解析”的问题。下载见 [GitHub Release](https://github.com/Hubujiu/SCAU-Link/releases/tag/v0.14.3-preview)。

保存校园网账号密码，连接有线 802.1X、SCAUNET Web 或 SCAUNET_1x。套餐使用保存凭据独立访问学校自助服务；联网成功不等于自助查询登录通过。

如果套餐仍未知，确认实际运行 0.14.3，在普通窗口的连接主页展开详情，查看是否提示自助服务拒绝及具体代码。“记录”页会显示套餐查询登录未通过。无需通过浏览器登录才能收集客户端诊断。

请发送具体拒绝码，或 `%LOCALAPPDATA%\ScauLink\logs\desktop.jsonl`，附出错时间、连接方式和版本。不需要提供密码或整个数据文件夹。

0.14.2 到本版的认证核心及运行库摘要相同，可按签名兼容信息使用无需断网更新；已运行的界面在下次启动加载新版。正常查询五分钟刷新，登录拒绝按至少 60 秒的重试间隔处理。详细说明见 [套餐查询文档](Package-Query-0.14.3.md)。

本版已验证本机有效账号查询与不含真实凭据的拒绝样本，报告故障的电脑仍待具体拒绝码复测，尚未确认其余额查询恢复。
