# SCAU Link 0.13.0

安装和校园网连接沿用 [0.12.0 使用说明](SCAU-First-Run-0.12.0.md)。在账号页保存账号和密码，连接页选择有线、SCAUNET Web 或 SCAUNET_1x；开机自启默认跟随上次选择，也可指定备用顺序。

本版新增设置页“检查更新”：检查、下载、安装并重启。默认空闲两分钟后后台检查和下载，六小时检查一次；只有客户端已断开，且没有账号编辑、确认操作或菜单时才自动安装。更新不会主动断网。

原安装路径和用户账号、设置继续使用。安装助手先等待原进程正常结束，再运行通过签名与摘要核对的安装包；静默启动仍保持静默。小窗设置仍只提供退出小窗模式。

0.12.0 及更早版本没有内置更新，需要手动安装本版一次，之后使用新模块。详情见 [更新与分发](Updates-0.13.0.md) 和 [验证范围](Network-Delivery-Results-0.13.0.md)。
