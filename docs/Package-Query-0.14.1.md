# 套餐查询修复与验证

0.14.1，2026-11-15。最终发布时间以 [GitHub Release](https://github.com/Hubujiu/SCAU-Link/releases/tag/v0.14.1-preview) 为准。CI 只编译、运行测试；客户端仅接受版本更新且带有效 Ed25519 签名元数据、安装包的 Release，同版本重新跑 CI 不会提示更新。

## 查询链路

Web 和 SCAUNET_1x 认证负责放行网络。套餐使用保存的账号密码独立访问固定学校主机 `mavis.scau.edu.cn:8443`，不读取浏览器登录状态：

1. 通过所选校园网卡发起兼容编码的 `GET /selfservice/module/scgroup/web/login_judge2.jsf?s=...`，解析账号摘要。
2. 使用该响应内已验证的业务入口建立独立临时会话。
3. 读取 `portal_packagemoney.jsf` 的余额与账期，再读取 `consume.jsf` 的周期费用；账号数据与完整周期冲突时不合并。
4. 缺少服务器到期日时，根据余额可支付的完整周期显示“预计到期”；不把预测写入服务器原始日期字段。

认证成功不证明自助服务可访问；“未知”原先同时可能表示未发起查询、网络/TLS 失败、未知返回格式或缺少字段。

## 修复的具体缺陷

- 网络已放行但无法确认在线账号时，主页清空了活跃账号，原查询条件因此直接跳过请求。现在分别保留套餐查询账号与在线账号身份；显示“账号未确认 · 套餐账号 …”，查询保存账号的账务信息，不将其冒充为已认证账号。
- TLS 冷却期间的缓存命中也会刷新五分钟截止时间。15 秒一次的界面检查使截止时间不断向后推，无法重新请求。现在只有真实请求失败才设置冷却，切网/重连清除旧冷却。
- 无线后台任务原来只传 MAC，并在查询时允许改用其他物理网卡。现在固定无线接口索引，不在目标接口尚无有效 IPv4 时改用其他网络；请求内的 IPv4 使用同一次网卡选择结果。网卡枚举、DNS 和 TCP 绑定均选择 Preferred 地址，排除 APIPA 作为 DNS 请求源地址。
- 余额未知时，主页直接显示套餐查询状态。后台增加数字阶段、接口索引、HTTP 状态、网络/TLS 错误及详情状态日志，不记录账号、密码、金额、原始响应、会话 Cookie。

## 轮询

只在普通窗口的已连接主页或账号列表可见时运行；隐藏、最小化、小窗、其他页面停止主动轮询。界面每 15 秒检查到期任务，不是每 15 秒发一次请求。

| 结果 | 下次允许请求 |
| --- | --- |
| 余额与计费数据已取得 | 查询完成后 5 分钟 |
| 缺少费用，或同时缺少扣费日和周期末日 | 30 秒，最多补查 3 次，之后 5 分钟 |
| 网络错误 | 5 秒，通常在下一次 15 秒界面检查时重试 |
| 查询认证拒绝 | 60 秒 |
| TLS/证书错误 | 站点冷却 5 分钟，缓存检查不延长冷却 |
| 其他错误 | 15 秒 |

进入相关页面和连接成功也会检查任务，后台按账号与凭据版本去重。多账号查询串行执行，因此实际间隔可能稍长。

## 验证边界

新增离线检查覆盖冷却到期、重连重置、多网卡绑定、无有效校园 IPv4、请求 IP、未确认在线身份与独立账务查询。原生应用演示检查覆盖网络可用但账号未确认与 1x 场景的余额展示，使用合成账号。

只读实网检查使用本机保存的自有账号，不重新执行校园网认证。其他电脑仅反馈“最新版、未知”，尚无其失败阶段或错误码，不能据此认定上述任一缺陷就是该电脑的唯一根因；真实 Web/1x 新登录后的跨机器验证仍待完成。当前真实认证进程和用户配置未替换。
