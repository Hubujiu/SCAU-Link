# SCAU Link 0.14.5 验证范围

- Windows 凭据管理器夹具覆盖旧目录迁移、两套密码独立保存、账号绑定、单独更换或清除，以及写入失败回滚。
- 后端夹具覆盖空缺统一门户密码时跳过自助查询、测试时使用暂存或已保存的门户密码、查询缓存按门户密码版本隔离、暂停和恢复的一次性确认。
- 普通窗口和小窗的原生控件测试输入两套不同的测试密码，核对自助服务测试拒绝和成功文案。另核对原有主页账务显示。 [原生交互记录](ui-native-0.14.5-preview/interaction-checks.json)
- 真实学校自助入口的无凭据探针通过证书校验，并返回完整的 HTTP 200 与业务拒绝码 0。真实统一门户凭据成功后取得的余额、套餐和在线设备数，本版尚未复测。
- 真实暂停、恢复、重新联网与改密不在本版验证范围内。构建产物版本和本地测试计数见验证清单。 [验证清单](validation-0.14.5.json)
