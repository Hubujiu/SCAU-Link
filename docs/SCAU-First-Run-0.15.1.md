# SCAU Link 0.15.1 初次使用

0.15.1 恢复 0.14.5 的原生界面和认证核心。从 0.15.0 更新时需要完整安装，手动安装会提示可能断网。0.14.4 及更早版本须手动下载安装以取得现有签名公钥。退出托盘里的旧客户端后可安装到原目录，原账号和设置会保留。 [下载安装包](https://github.com/Hubujiu/SCAU-Link/releases/tag/v0.15.1-preview)

首次联网，在“账号”中输入校园网账号和校园网密码，然后按“登录”。升级时沿用已保存的校园网账号和校园网密码。

需要查询余额、套餐或在线设备数，或管理校园网暂停和恢复时，在账号横条的右键菜单选“管理”，填写同一账号的统一门户密码。点“测试”会向学校发起只读自助查询，显示登录是否通过、查询是否返回数据。测试通过后点“保存”。统一门户密码选填，空缺时可以正常联网。

编辑已有账号时，留空保留各自已保存的密码。要删除统一门户密码，点它旁边的“清除”，然后保存。修改账号名称时，请为新账号填写对应密码。
