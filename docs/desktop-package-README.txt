SCAU Link {VERSION} · Windows x64 原生客户端

运行 SCAU-Link.exe，保持 scau-auth.exe、scau-update.exe 和运行库 DLL 在同一目录；三个程序一起更新。
首次在账号页保存校园网账号和密码，连接页选择有线 802.1X、无线 Web 或无线 802.1X。
三种方式共用保存的账号，不需要抓包、原锐捷或导入认证配置。
无线自动连接 SCAUNET / SCAUNET_1x，1x 使用固定同名配置及当前用户 EAP 凭据，不使用 Windows 登录凭据。
有线需要已有 WinPcap/Npcap；无线无需 Npcap。系统需要有效 IP/DNS，产品不会自动修改主机 IP 配置。

开机自启默认关闭，开启后自动使用保存的凭据。默认跟随上次手动选择的方式，也可指定先后尝试的方式。
选定第一种开机方式后才展开备用项，成功后停止尝试；备用连接不改变上次手动选择。
静默启动不弹窗口或通知，失败也静默；从托盘打开可查看状态。
认证核心异常恢复、连接通知、关闭到托盘固定开启。
小窗居中，只保留连接操作；小窗设置只有“退出小窗模式”。

设置页“检查更新”支持检查、下载、安装并重启。
默认空闲两分钟后后台检查并下载，每六小时检查一次；失败退避半小时。
只有断开连接、核心退出且没有编辑、确认或菜单交互时才自动安装；更新不会主动断网。
更新使用固定 GitHub 仓库、标准证书验证、Ed25519 签名及 SHA-256 校验。
独立助手等待主进程退出后安装到原目录；0.12.0 及更早版本需手动安装本版一次。

账号为独立圆角横条，右键管理、修改密码、校园网、删除、置顶；置顶就是第一行。
按住横条约 0.22 秒浮起，拖动排序，松手保存；Esc 取消，点击空白取消选中，也可 Alt+↑/↓ 排序。
调用用户的 Windows 系统手形 IDC_HAND，无打包指针资源；Win32 没有独立握拳状态。
明确的账号拒绝重试一次，仍失败尝试下一行；环境问题和未知认证结果不盲目换号。
认证成功账号显示“活跃中”；Web 已放行但未确认账号时显示“账号未确认”。
失败显示可用的服务端原因，未提供或无法识别时显示 unknown；原文不写公共记录。

主页显示认证账号、余额和已知期限；账号右侧显示余额、周期费用、下次扣费。
实际日期与“预计下次扣费”区分，未知不当零，不按余额猜测账号失效日。
套餐使用所选物理接口的 IP/MAC/DNS，首次无线连接也无需有线配置；重连后自动重查。
可见主页和账号页定时刷新，隐藏、小窗和静默状态不主动查询；短暂失败退避后重试。
在线数未知不当零；设备明细仍可能受学校端查询失败影响，不提供踢设备。
校园网暂停／恢复须在面板确认，只提交一次，超时只读核对；真实操作本轮未提交。
修改密码只在服务端明确成功后更新本机凭据；本轮未提交真实改密。

记录支持搜索、状态/时间范围筛选和时间/失败优先排序，每次显示最多 500 条匹配记录。
细圆角连续滚动条，滚轮弹簧过渡，拖动跟手，静止停止动画；整帧缓存避免闪烁。
原生菜单、图标和圆角统一，页面按需创建，字体和画刷缓存，无网页运行时。

配置与记录：%LOCALAPPDATA%\ScauLink；账号名和密码保存在当前用户的 Windows 凭据管理器。
accounts.dat 只保存随机标识和顺序，密码不写配置、日志或命令行。
有线参数在本机生成，此包无私人配置、抓包、Cookie 或登录凭据。
学校旧证书兼容只用于指定学校端点，不修改系统信任或其他网站校验。

最终构建 CTest 35/35，包含更新模块 85 项检查及 17 项离线实验故障检查。
真实 QA 安装包在普通用户的隔离中文目录通过安装、摘要核对及卸载；当前联网程序和账号设置未变。
新增更新按钮因 Windows 锁屏未能完成点击验证，未用旧版截图代替。
认证核心与 0.12.0 相同；此前普通权限下实测两次 Web 新登录、1x 登录及核心崩溃重登、无线绑定上网和套餐字段。
