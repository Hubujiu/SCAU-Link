# 0.14.2 套餐诊断与详情恢复验证

2026-11-15，0.14.2 预览版。最终发布状态以 [GitHub Release](https://github.com/Hubujiu/SCAU-Link/releases/tag/v0.14.2-preview) 为准。

## 验证范围

- 合成摘要没有余额、费用和名称但保留合法详情入口时，继续完成四次隔离只读请求，取得余额和周期费用；无入口、外部入口、空列表或网页返回不会触发猜测请求。
- 区分 HTTP 200 但正文不完整、空正文、网页、非法 JSON、信封或列表类型错误，以及没有已知字段的列表。
- “记录”解析检查覆盖旧版数字错误状态、成功状态、摘要失败、筛选和搜索；非法数值和原始诊断文本不进入显示结果。
- 原有费用一致性、取消、多网卡、冷却及更新验证仍由完整 Release CTest 执行。构建结果、程序摘要和检查总数记录在 `validation-0.14.2.json` 及安装包的 `verification.json`。
- 本次完整 Release 构建通过，CTest 36/36 通过；原生合成主页检查 2/2 通过。日志保存在 `network-delivery-0.14.2/ctest.txt`。
- 共享日志读取代码改变了认证核心二进制摘要，因此从 0.14.1 更新时按完整安装流程处理，自动安装等待连接已断开。

## 实际边界

报告电脑的旧日志只定位到账号摘要阶段，不能区分响应完整性与正文解析的具体分支。新诊断和提前退出修复已经加入，仍需在该电脑运行新版取得结果；不声称已复现其学校原始响应或已解决该电脑全部问题。

未替换或安装到用户当前运行的校园网客户端，未停止认证进程、切换网络或提交改密、暂停/恢复操作。未在本轮重新测试真实无线新登录、其他电脑、实际重启、漫游或长时稳定性。合成原生控件检查不代表完整视觉检查。
