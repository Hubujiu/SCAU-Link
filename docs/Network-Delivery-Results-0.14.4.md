# 0.14.4 自启和有线诊断验证

2026-11-16，预览版。发布时间以 GitHub Release 为准。

## 本轮验证

- Windows x64 Release 构建及 CTest 37/37。
- 使用随机名称创建真实、当前用户、普通权限的登录任务，验证零延迟、正常优先级、电池可用、不等待网络、无运行时限、路径含空格和 XML 特殊字符的还原、禁用和删除。测试不运行该任务，结束后清理，不修改正式自启。
- 卸载清理回归：其他路径的副本不能删除当前任务，匹配路径可以删除。
- 合成工作进程在 ready 前返回驱动错误，验证私有通道保留中文原因，不当作崩溃重启；桌面后端验证环境错误不会轮换账号。
- 既有自动恢复、连接模式切换、账号、协议、更新签名和两种原生合成主页场景回归。
- 隔离安装测试 29/29：自定义中文路径、升级、运行互斥保护、卸载和无关文件保留。测试使用独立 AppId 和注册表项，没有启动应用或认证，没有改动正式自启及保存账号。生产登录任务的创建和卸载归属由独立 C++ 测试验证；未对正在运行的正式安装执行升级。
- 本机只读诊断显示旧 WinPcap 存在、NPF 服务停止。启动服务的尝试返回 Windows 拒绝访问（5），服务状态未改变。

## 未验证

没有重启 Windows、切换或断开现有网络，没有覆盖安装到当前运行的客户端。未实测完整登录耗时、实际驱动修复后的有线认证、真实备用网络切换、休眠恢复或长时稳定性。普通权限下无法启动旧 NPF 的本机环境问题尚未修复，不宣称升级即可恢复有线网络。原始日志、用户名、网卡标识和私有配置不进入发布材料。

认证核心摘要改变，本版不属于与 0.14.3 兼容的免断网界面更新。安装包和便携包使用同一构建，更新元数据由既有本地签名身份生成。
