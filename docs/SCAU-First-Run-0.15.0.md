# SCAU Link 0.15.0 初次使用

首次联网时，在“连接”页选择有线 802.1X、无线 Web 或无线 802.1X。点击“登录”，保存校园网账号和校园网密码。升级时可以沿用已保存的账号和设置。有线模式需要电脑上已安装 Npcap 或 WinPcap。

在线时，主页显示可取得的余额和到期时间。“连接详情”展开在线时长、网卡和在线设备数。小窗保留连接状态和登录操作，连接方式在普通窗口中选择。

统一门户密码选填，用于自助查询、套餐和校园网暂停／恢复。打开“账号”，在账号横条的右键菜单选“管理”，输入同一账号的统一门户密码，点击“测试”后保存。已有账号的密码字段留空会保留已保存的值。

从 0.14.5 升级会更换认证进程，在线时客户端会等待断开，或在手动安装前提示。从 0.14.4 或更早版本升级，请手动下载安装包以取得新签名公钥。退出托盘里的旧客户端后可安装到原目录。 [下载安装包](https://github.com/Hubujiu/SCAU-Link/releases/tag/v0.15.0-preview)
