# 不断网更新与更新提示

0.14.0 起，下载前核对签名兼容说明和本机 `scau-auth.exe`、四个应用本地 VC++ 运行库的 SHA-256。五个文件均与目标版本相同，且发布包含有效的签名不断网更新包时，显示“无需断网”；其他情况显示“更新时可能断网”。缺少兼容说明的旧发布保守采用完整安装流程。

本版启用 MSVC 确定性编译/链接，避免源码不变但时间戳等构建数据变化造成摘要误判；使用的 `/Brepro` 也见 [Microsoft Windows App SDK 构建配置](https://github.com/microsoft/WindowsAppSDK/blob/main/WindowsAppSDK.Build.Cpp.props)。该切换本身改变了旧核心的二进制摘要；从旧版首次升级仍需完整安装，不把不一致的文件当成已兼容。

## 无需断网

空闲两分钟后可自动下载、安装，手动安装也无需停止连接。更新只替换磁盘上的桌面程序、更新助手和对应源码/说明，保留原进程、认证工作进程、进程作业和管道。当前窗口继续使用已加载的代码，显示“已更新 · 下次启动生效”；新界面在下次启动时生效。不会伪装成运行中的界面已经换版。

认证核心和运行库在整个替换期间持有防写/防删除句柄，不在更新包可写路径名单中。先校验并分块解包到安装盘内的独立目录，再同卷重命名替换，桌面程序最后替换。保留已映射的旧文件，失败逆序回滚，下次启动后清理成功事务的旧副本。文件占用、路径异常或摘要变化均拒绝继续，不降级为主动断网安装。

## 更新时可能断网

认证核心/运行库变化或没有可靠兼容证据时，只自动下载，在线状态不自动安装。手动点击“安装并重启”显示“更新时可能断网”，确认后才请求断开；默认选择取消。等待认证核心真正停止后才交给原安装助手。用户取消时保留当前连接。

已断开且没有编辑、确认或菜单交互时，仍可在空闲期间自动安装。认证进行中或正在恢复时，不启动不断网替换。小窗设置仍只保留退出小窗模式。

## 发布

保留 0.13.0 使用的九字段 `SCAU-Link-update.json` 及签名，以便旧版获取完整安装包。新增独立签名 `SCAU-Link-live.json` / `.sig`，绑定同版本完整安装包的摘要、本机受保护文件的摘要和不断网包的地址/大小/摘要。旧版首次升级仍按其原有流程执行，升级到本版后使用新规则。

构建、打包后运行：

```powershell
python scripts/sign_release.py sign --installer out/SCAU-Link-0.14.0-Setup-x64-preview.exe --version 0.14.0 --with-live
```

不断网包采用受限二进制格式，只接受六个固定路径，无脚本、任意路径、配置或凭据内容。使用现有 Ed25519 发布身份，标准 Windows TLS 校验不变，私钥不发布。文件替换使用 Windows [MoveFileExW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-movefileexw)，不使用重启后替换选项。
